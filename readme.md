# Sprint 2 - Relational Databases

This project builds a database, that holds multiple tables to track movies I have rated. I can then
take the information that I have found, and query it to find specific movie ratings and specific movies
higher than inputed ratings.


## Instructions for Build and Use

Steps to build and/or run the software:

1. Import sqlite3
2. build a database
3. build tables to populate the database
4. add information to the tables
5. join tables together to get more information on one table
6. update table information
7. write functions to query the tables, to query the data to find specific results

Instructions for using the software:

1. Open the console
2. type in python question.py, or just question.py, or just hit the run button on the top right
3. follow the instructions of the prompt

## Development Environment 

To recreate the development environment, you need the following software and/or libraries with the specified versions:
